### How to install & open on macOS
1. Download `Websitenator-3000-Mac.zip` from the **Releases** section on the right.
2. Double-click the `.zip` file to extract it, then drag **Websitenator 3000.app** to your **Applications** folder.
3. The first time you open it, macOS will block it because it is an independent open-source app:
   - Click **Done** on the pop-up.
   - Open **System Settings > Privacy & Security**, scroll down, and click **Open Anyway**.
